# 小红书文案风格模板

AI Agent 系统提示词中引用的10种文案风格模板。

## 通用风格

```
【开头】：用1-2个emoji + 吸引人的标题，营造氛围。
【正文】：包含3-4个要点，每个要点前加emoji符号，条理清晰，信息丰富。
【总结】：用简洁有力的语言总结核心观点，增强印象。
【互动】：设计贴合内容的互动引导语，鼓励用户点赞、收藏和评论。
【标签】：添加3-5个与内容高度相关的话题标签，方便内容传播。
```

在 Edit Fields 节点中配置这些模板，通过 Code 节点根据用户选择的风格匹配对应模板，传递给 AI Agent 的 systemMessage。
